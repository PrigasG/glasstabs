\mysection{Setup}

Load the dependency once in the UI:
\begin{lstlisting}

ui <- fluidPage(
  useGlassTabs(),

\mysection{Layout and responsive choices}

\begin{itemize}
  \item \gtarg{orientation}: horizontal row or vertical rail.
  \item \gtarg{tab\_align}: places the tab group.
  \item \gtarg{text\_align}: aligns labels inside buttons.
  \item \gtarg{indicator}: glass halo, solid fill, or underline.
  \item \gtarg{shape}: rounded or square tabs.
  \item \gtarg{overflow = "scroll"}: one horizontal row; selected tab stays visible.
  \item \gtarg{overflow = "multiline"}: tabs wrap onto rows.
  \item \gtarg{overflow = "menu"}: native compact menu; horizontal only.
  \item \gtarg{swipe = TRUE}: guarded horizontal pane gestures.
  \item \gtarg{compact = TRUE}: tighter dashboard-card spacing.
\end{itemize}

\begin{lstlisting}
glassTabsUI(
  "mobile", ...,
  overflow = "menu",
  swipe = TRUE,
  text_align = "left"
)
\end{lstlisting}

\columnbreak
\mysection{Keyboard and accessibility}

Built in:
\begin{itemize}
  \item Arrow keys move through tabs; orientation chooses the axis.
  \item Home and End move to the first and last available tab.
  \item Enter or Space activates the focused tab.
  \item Disabled tabs remain discoverable but cannot activate.
  \item Inactive panes are inert and outside the focus order.
  \item Reduced-motion and forced-colour preferences are respected.
\end{itemize}

\mysection{Server-side search}

Use for large choice collections. The UI and server IDs match.
\begin{lstlisting}

glassMultiSelect(
  "people", character(),
  server = TRUE,
  server_limit = 40L,
  server_min_chars = 2L
)
glassSelect(
  "city", character(),
  server = TRUE
)

# Server
glassMultiSelectServer(
  "people", people_choices,
  session = session,
  limit = 40L,
  ignore_case = TRUE

  "city", city_choices,
  session = session
)

\mysection{Common gotchas}

\begin{itemize}
  \item Call \gtfn{useGlassTabs} once unless using \gtfn{glassPage}.
  \item Panel \gtarg{value}s must be unique; \gtarg{selected} uses values, not labels.
  \item Modules use \code{ns("tabs")} in UI and bare \code{"tabs"} in server.
  \item \gtarg{overflow = "menu"} supports horizontal tabs only.
  \item Swipe ignores interactive and scrollable content.
  \item \gtfn{glassSelectValue} returns one reactive function.
  \item \gtfn{glassMultiSelectValue} returns \code{selected()} and
        \code{style()} reactives.
  \item Server-side choice functions belong in the server.
\end{itemize}
